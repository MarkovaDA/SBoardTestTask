# Требования к тестовому заданию

Положите PDF с формулировкой задания сюда:

**`docs/requirements.pdf`**

После сохранения файла напишите в чат: «PDF в docs/requirements.pdf» — ассистент прочитает и разберёт список требований.

Альтернатива: прикрепите PDF к сообщению в Cursor (перетащить в поле ввода).
